## `$ whoami`

I'm an Information Technology undergraduate at the University of Moratuwa, Sri Lanka, building my foundations in cybersecurity through hands-on labs, technical projects, and continuous learning.

My main interests are defensive security, Security Operations Center (SOC) analysis, threat hunting, incident investigation, and ethical hacking.

- 🎓 **Education:** BSc (Hons) in Information Technology
- 🛡️ **Current direction:** SOC analysis and Blue Team security
- 🔎 **Exploring:** Network threat hunting, log analysis, and incident response
- 💻 **Hands-on practice:** Linux, Python, networking, security tools, and virtual labs
- 🚩 **Also interested in:** Web application security and vulnerability assessment
- 🎯 **Goal:** Build practical security skills and contribute to protecting systems and users

I believe cybersecurity is best learned by investigating real evidence, documenting findings, understanding the underlying technology, and continuously improving.
